# Lakshita Rawat — Portfolio

A responsive, minimal dark portfolio page built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload `index.html` to your portfolio repository.
2. In GitHub, open **Settings → Pages**.
3. Select the branch and root folder, then save.

## Adding project thumbnails
Use the **Add a project & thumbnail** form in the page to preview an additional card. To make a project permanent on the published site, update the project card markup in `index.html` and add the thumbnail image to the repository (for example, `assets/my-project.png`) and set the image source to that path. Browser-uploaded images in the add form are for the current preview/session only and are not uploaded to GitHub automatically.
